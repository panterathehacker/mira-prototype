# Mira

An enduring-partnership agent for an early-stage consumer investor. Built as a prototype for the Google AI Studio MTS take-home assignment (Option 3: Agents and continuity).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
